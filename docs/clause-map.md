- **046**：T/CAAAD 046—2026

- **026**：T/CAPT 026—2026

## 1. geo-facts 功能与条款号对照

| 模块 / 功能 | 具体机制 | 对应条款号 | 说明 |
|---|---|---|---|
| 工具定位与预检边界 | CLI 与报告只给预检结论与建议，不自称独立第三方验证 | `047 §15.2` | 见 `geo-facts` 帮助信息、`calibrate` 与 `gate` 输出的预检提示 |
| 禁止效果保证 | 不输出对第三方平台展现、排名或收录结果的保证性表述 | `046 §7.1.4`、`047 §13.2` | 规则输出与文档均遵守该边界 |
| 离线与合规采集边界 | 默认离线规则实现，不实现代理池、账号池、验证码绕过、反爬规避或设备指纹伪装 | `046 §8.4.4`、`047 §10.1` | 架构边界；模型插件接口默认不启用 |
| 只纠错不压制负面 | 只支持纠正错误与过期信息，不实现压制、挤出真实负面信息的功能 | `047 §9.3` | 事实核验与闸门均按此设计 |
| 原始记录与变更留痕 | `entities.jsonl`、`facts.jsonl`、`audit.jsonl` 只追加不覆盖，哈希链记录变更前后状态 | `047 §14` | `validate STORE` 校验审计链完整性 |
| 核心事实证据绑定 | 核心事实须绑定来源等级、来源名称、原始链接或文件、采集时间、最近核验时间、审核责任人、有效期、版本号、证据编号；企业官网默认 C 级且来源等级与内容用途独立 | `026 §6.2` | `validate STORE` 检出无证据核心事实；`gate` 通过 `G-FACT-STALE` 拦截无证据核心事实 |
| 事实库三区分治、时效与冲突清单 | 事实/观点/营销三区分治，`--as-of` 按日取有效版本，冲突不自动裁决 | 待人工核对 | 详见 [方法学](methodology.md) |
| 文本、数值、单位、日期、型号与条件归一 | 约数容差、单位换算、日期精度、条件不可比原则 | 无对应条款，本工具自定规则 | 详见 [方法学](methodology.md) |
| 陈述拆解与双向判定 | 回答 → 事实库（准确率两口径）与事实库 → 回答（呈现率），两个分母互不混用 | 待人工核对 | 验收口径须事前登记 |
| 判定校准与精度不足门槛 | 按人工金标算混淆矩阵与 Wilson 区间，错误率上限超 `1 - target` 时输出“判定精度不足” | 无对应条款，本工具自定规则 | 详见 [方法学](methodology.md) |
| 闸门：`G-FACT-CONTRADICTION` | 稿件陈述与有效事实矛盾（`block`） | 待人工核对 | 详见 [闸门规则](gate-rules.md) |
| 闸门：`G-FACT-STALE`（无证据核心事实） | 稿件使用缺少证据的核心事实（`block`） | `026 §6.2` | 其余过期/撤回/已更正版本标注“待人工核对” |
| 闸门：`G-TIME-FORGED` | 检查伪造、晚于当前时间或早于创建时间的更新时间，工具不改写任何时间（`block`） | `026 §7.3` | 同时覆盖 `meta` 与正文声称的更新时间 |
| 闸门：`G-LEXICON` | 合规词库命中（极限词、夸大承诺、行业敏感词）只产生 `review`，永不单独作为 `block` | `046 §8.3.5` | 内置示例词库未经法务审阅；外部词库白名单外条款号自动替换为“待人工核对” |
| 闸门：`G-DRUG-COMPARISON`、`G-RX-PROMOTION` | 药品功效比较、处方药面向大众推广（`review`，最高风险级别并要求法务确认） | 待人工核对 | 详见 [闸门规则](gate-rules.md) |
| 闸门：`G-HIDDEN-TEXT`、`G-PROMPT-INJECTION`、`G-COMPETITOR-COMPARISON`、`G-NEAR-DUPLICATE`、`G-AI-LABEL` | 隐藏文本、提示词注入、竞品比较、同品牌同主题近似重复、AI 标识状态 | 无对应条款，本工具自定规则 | 详见 [闸门规则](gate-rules.md) |

## 2. 本仓库不涉及的条款说明

- `047 §8.3`（样本充分性要求：多时间窗口与最低有效观测次数）属于效果监测与统计验收范畴，由独立仓库 `geo-verify` 落实，本仓库不重复计算。
